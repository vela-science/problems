# Designer Acceptance Checklist

## Strategy
- [ ] Category claim is preserved.
- [ ] Identity communicates state and lineage before generic acceleration.
- [ ] Astronomy/navigation is a semantic layer, not a visual cliché.

## Logo
- [ ] Full, compact, and micro masters are separately drawn.
- [ ] Monochrome test passes.
- [ ] 16 px favicon test passes on macOS, Windows, iOS, and browser tabs.
- [ ] Wordmark is custom artwork.
- [ ] Clear space and minimum sizes are documented.
- [ ] Similarity/trademark screen is complete.

## System
- [ ] WCAG contrast pairings are documented.
- [ ] Data-viz palette works for common color-vision deficiencies.
- [ ] Motion includes reduced-motion behavior.
- [ ] Templates are editable and use named styles/tokens.
- [ ] Print proofs include coated, uncoated, and metallic samples.

## Handoff
- [ ] Source files are organized and named consistently.
- [ ] Fonts and licenses are documented, not bundled without permission.
- [ ] Exported assets match source geometry.
- [ ] README and CHANGELOG are complete.
