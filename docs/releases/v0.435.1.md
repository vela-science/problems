# Vela Web v0.435.1

Vela Web 0.435.1 completes the production human-account path introduced in
0.435.0.

- Production uses WorkOS Magic Auth for passwordless email verification.
- The production owner invitation, verification, callback, and account session
  have been exercised end to end.
- The account menu explicitly requested its POST-only sign-out form.
- Production qualification found that the menu could unmount that form before
  navigation completed. Version 0.435.2 supersedes this implementation.

Human web identity remains separate from Vela actor identity and carries no
scientific authorship, signature, Verification, Decision, or repository
authority.
