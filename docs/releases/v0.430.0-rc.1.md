# Vela Web v0.430.0-rc.1

Vela Web 0.430.0-rc.1 is the release candidate for the bounded, first-party
Math Atlas alpha. It keeps the four Git Frontier repositories authoritative
and makes their exact current state, source coverage, and next work visible
through a disposable read projection.

The candidate:

- binds released Vela `0.950.1` by exact platform-specific binary bytes;
- refreshes all eight externally acquired sources through exact adapter
  bundles, checks them against explicit rights and redistribution declarations,
  retains 14 declared source observations plus direct Frontier and local
  bindings, and fails closed on missing required acquisition coverage;
- retains source observations independently of web releases and validates old
  observations against the declaration stored with their release;
- exposes the Math Source Registry and the existing Observatory as the bounded
  Math Atlas rather than creating another registry, graph store, or authority;
- projects all four clean Frontier tips, including the current bounded quantum
  admission Target;
- verifies the rooted 100,000-record synthetic generation benchmark, which
  establishes deterministic chunking and cursor behavior only, not Neon,
  concurrency, egress, or production-scale performance;
- keeps the application reader SELECT-only and all scientific Decisions in the
  canonical Frontier repositories; and
- requires one immutable adapter set and one dry-run candidate root before any
  projection write.
