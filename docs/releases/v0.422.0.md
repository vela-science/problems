# Vela Web v0.422.0

Vela Web 0.422.0 moves the read-only Observatory to the current repository
epoch and the Claim, Submission, Verification, and Decision vocabulary.

This release:

- reads normalized `observatory.v4` rows through
  `vela.observatory-release-manifest.v5`;
- binds released Vela `0.940.5` and the exact current Git and repository roots
  of all four published Frontiers;
- distinguishes the producer Submission, scoped Verification Record, pending
  Proposal, terminal Decision, and derived Claim Standing;
- resolves current `vcl_` Claim routes to retained imported `vf_` graph
  identities without conflating the object families;
- preserves the complete rooted Erdős graph of 4,668 nodes and 5,035 edges;
- keeps the Neon read model disposable and SELECT-only; and
- requires staged Vercel production builds plus explicit promotion, so a Git
  push cannot silently change either public product.

The activated projection is:

```text
sha256:5e34b24d33ed7034e2872f5731d7380afcc5ce2c0adea2fb833b8f98b557b42c
```

Its stored table roots and graph counts were reverified before the atomic
current-release pointer change. The previous released root remains retained
for rollback compatibility.

This release changes no canonical Frontier byte, accepted Claim Standing,
repository authority rule, protocol schema, or editorial route.
