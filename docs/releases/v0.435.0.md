# Vela Web v0.435.0

Vela Web 0.435.0 introduces optional human accounts without changing Vela
actor identity, scientific authority, or the public read model.

- WorkOS AuthKit supplies maintained sign-in, callback, session, and sign-out
  primitives. No custom credential store or token format was added.
- Public scientific routes remain anonymous, static where their data permits,
  and bound to the same exact projection release root.
- Account state is confined to dedicated auth routes and a compact header
  control. The browser receives only display name, email, and initials; the
  provider user ID remains server-side.
- Sign-out is POST-only and exact-origin checked. Account responses are private,
  no-store, and vary on the session cookie.
- An unconfigured deployment fails closed: it does not render a broken sign-in
  control and leaves the public Observatory available.

A signed-in human account is not a Vela actor, signer, author, verifier, or
Decision authority. This release adds no scientific mutation route and makes no
change to a Frontier repository or its Standing.
