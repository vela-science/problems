# Vela Web v0.433.0

Vela Web 0.433.0 publishes the first frontier-to-commons proof on the problem
map.

- `/problems` now presents Erdős 264, Erdős 521, and Erdős 730 as three
  explicit source-qualified dispositions instead of implying that every strong
  artifact should become an upstream contribution.
- Erdős 521 has an exact reviewer packet for the existing Formal Conjectures
  pull request. It verifies the complete 154-file proof dependency closure,
  the statement bridge, the accepted axiom boundary, and the distinct-root
  fidelity question that the upstream file-local check does not cover.
- Each dossier exposes its native owner, next gate, exact source record,
  authority boundary, and machine-readable JSON from the same immutable
  Observatory release.
- The current release binds Erdős Frontier `80cb9f33...` and Formal Conjectures
  Frontier `4b6adc69...` at release root `sha256:ce9985d8...`.

This release adds no Vela protocol object, package infrastructure, source-
specific Vela core code, database migration, or external acceptance claim. The
Observatory database remains one unnumbered current projection and the deployed
application remains SELECT-only.
