# Vela Web v0.430.0-rc.3

Vela Web 0.430.0-rc.3 is the first candidate built from the current exact
eight-source Math Registry and the current heads of all four canonical
Frontiers. Git remains authoritative; Neon remains a disposable, SELECT-only
read projection.

The candidate:

- binds the released Vela 0.950.1 macOS binary at
  `sha256:e9bc81e1bb735ade94a529253bec96ea6a8c5618a524c0e4b3e53c5846e8535e`;
- acquires the PLBY manifest from the exact pinned Git commit and byte root
  instead of the historical Frontier reconciliation file;
- retains 6,700 exact source-adapter records, including 201 current PLBY
  entries, without treating source labels as Vela Verification or Standing;
- projects 9,537 source-native records and 6,303 explicit Frontier bindings;
- projects the current Erdős, Formal Conjectures, Quantum Codes, and Sidon
  Frontier heads, including three verified Proposals that remain
  `pending_review`;
- exposes the Math Sources reader from the Observatory while keeping the
  editorial application independent of Neon; and
- keeps the application role SELECT-only and all scientific Decisions in the
  canonical Frontier repositories.
