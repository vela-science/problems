# Observatory v0.360.7 release evidence

This patch closes the final cross-deployment usability defect found during the
v0.360 Browser audit.

- Next.js receives the exact deployment identifier already injected by Vercel.
  Client navigations and static assets therefore stay bound to one immutable
  deployment, and a version mismatch triggers a hard navigation instead of
  leaving a partially hydrated route.
- A disagreement between the framework and platform identifiers fails the
  build before deployment.
- Local development remains unbound. CI builds use the bounded source revision,
  and malformed explicit identifiers fail the build.
- v0.360.6 remains a stopped, non-production tag documenting the release-only
  mismatch that exposed this invariant.

No canonical frontier, protocol, authority, editorial, or accepted-state byte
changes are included.
