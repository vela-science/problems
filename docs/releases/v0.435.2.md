# Vela Web v0.435.2

Vela Web 0.435.2 completes production sign-out qualification.

- The POST-only sign-out form now remains mounted outside the transient account
  menu while the menu item requests submission.
- Closing the menu can no longer remove the form before the browser navigates.
- The exact-origin server boundary and WorkOS session termination remain
  unchanged.

Human web identity remains separate from Vela actor identity and carries no
scientific authorship, signature, Verification, Decision, or repository
authority.
