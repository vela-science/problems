# Vela Web v0.421.0-rc.1

Vela Web 0.421.0-rc.1 is the first Observatory candidate that reads Vela's
repository-authority migration boundary.

The candidate:

- pins the released Vela `v0.930.0-rc.6` projector binary and platform
  archives and records the exact Linux and macOS generator-binary checksums;
- projects the Formal frontier's signed authority record, public repository
  keyset, restricted policy identity, and exact migration roots into a
  read-only `site.repository-authority.v1` view;
- binds that view into `vela.observatory-release-manifest.v3` over
  `observatory.v2`;
- preserves the current strict-blocked Erdős state as visible debt instead of
  treating projection success as a strict pass;
- reuses an exact committed Profile view when its scientific, compatibility,
  and event roots already match, avoiding cross-version rematerialization
  drift; and
- leaves Era 0 frontiers without an authority record unchanged.

The browser receives public verification material only. It receives no private
key, SSH-agent handle, authentication context, semantic approval, signing
control, or mutation path.

This candidate changes no canonical frontier history, accepted scientific
state, authority rule, protocol object, or editorial route. Its database
migration is additive and release-scoped; production activation remains a
separate exact-root gate.
