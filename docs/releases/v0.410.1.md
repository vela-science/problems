# Vela Web v0.410.1

This patch makes the disposable Neon projection easier to operate without
changing any frontier, API, authority, or visual contract.

- Application reads use only the SELECT-only
  `VELA_PROJECTION_DATABASE_URL` credential.
- Migration apply, refresh, activation, and pruning use only
  `VELA_PROJECTION_WRITER_DATABASE_URL`.
- Generic `DATABASE_URL` and reader-as-writer fallbacks are removed.
- The duplicate reader-password secret is removed; provisioning validates the
  password already contained in the reader URL.
- Production remains one Neon project, one permanent `main` branch, one
  normalized database, and release-scoped rows behind `current_release`.

Canonical frontier repositories, normalized projection rows, public read
contracts, and scientific standing are unchanged.
