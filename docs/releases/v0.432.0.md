# Vela Web v0.432.0

Vela Web 0.432.0 makes the problem map the public entry point.

- `/problems` leads with exact questions, current bounded work, corrections,
  and complete case records instead of protocol objects.
- The first collection exposes all 1,217 rooted Erdős problem pages and the
  three current deep Erdős Result Dossiers from the same read-only release
  root.
- The landing page keeps source status, native proof checks, local Frontier
  Standing, and external maintenance state separate.
- Problem-number lookup moves directly into the rooted Erdős index. The page
  works at desktop and mobile sizes and uses the existing Vela Web shell and
  shared design system.
- The Observatory root and logo now lead to the problem map. The forensic
  Frontier, source, work, review, graph, and reproduction surfaces remain
  available without duplication.

The database remains the single unnumbered current Observatory projection.
This release adds no writer, protocol object, package registry, scientific
Decision, or external acceptance claim.
