# Vela Web v0.430.0

Vela Web 0.430.0 ships the first exact Math Source Registry and current
four-Frontier Math Atlas in the read-only Observatory. Canonical scientific
state remains in Git; Neon is a disposable projection that can be rebuilt from
the released Vela binary, pinned source adapters, and exact Frontier heads.

The release:

- binds Vela 0.950.1 and all four current Frontier commits and repository roots;
- projects 14 source observations, 9,537 source-native records, and 6,303
  explicit Frontier bindings;
- projects 2,836 Claims, 9 Verification Records, 4,135 graph nodes, 2,575
  edges, and 4,139 search documents;
- exposes exact source, evidence-lineage, correction-impact, and next-work
  context without treating graph position or Verification as Standing;
- retains one Neon `main` branch and a SELECT-only application role;
- preserves URL-backed Observatory navigation and the shared `@vela/ui` design
  system; and
- adds bounded Postgres read-health, 100,000-record capacity, and clean-room
  reconstruction evidence without adding another storage layer.
