# Observatory v0.360.2 release evidence

This operational patch keeps the exact-origin check fail-closed while treating
GitHub HTTPS URLs with and without the conventional `.git` suffix, and GitHub
SSH URLs, as the same repository identity.

The first automated projection refresh stopped before writing because the
Actions checkout URL and configured URL used different transport spellings.
Focused fixtures now accept only equivalent `github.com/<owner>/<repository>`
identities and reject credentials, lookalike hosts, and non-GitHub remotes.

No protocol, authority, canonical frontier, editorial, or accepted-state byte
changes in this patch.
