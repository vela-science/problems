# Vela Web v0.436.1

Vela Web 0.436.1 hardens the authenticated Problem Workspace boundary and its
touch interaction surface.

- Workspace selection now requires account membership and an exact Repository
  plus Problem match. A Workspace anchored to Erdős 887 can no longer appear
  while reading Erdős 321.
- The additive `20260813_problem_scoped_workspaces` function is live at
  `sha256:f10321db042198a32e7c6d77dedf83f9aa1ac52eb24ae97bc86240d297a5f6ce`.
  It remains account-scoped and exposes no scientific authority.
- Buttons, inputs, and select triggers use a 44px interaction floor for coarse
  pointers while retaining the compact desktop density.
- Authenticated production checks cover 320, 390, 768, 1024, and 1440 CSS-pixel
  layouts; reduced motion; forced colors; print; coarse-pointer controls; and
  the programmatic main-content destination. No horizontal document overflow
  was observed.
- The current public projection remains
  `sha256:5c0df33530097a06a3be49cc26eb79fa65d3db5e9bc9aa7c89ecc646ec95256b`.

This release changes hosted activity selection and presentation only. It does
not create or alter a Vela Submission, Verification, Decision, Event, or
