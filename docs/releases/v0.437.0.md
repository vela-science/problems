# Vela Web v0.437.0

Vela Web 0.437.0 is the Coherence cutover to one Core-owned scientific-state
projection and one current Problems product surface.

- `apps/problems` and `@vela/projection-data` replace the prelaunch
  Observatory names without aliases.
- Projection construction consumes the closed, root-bound Core export instead
  of interpreting Repository protocol envelopes in Web.
- Live Result Dossier, Work Offer, and stale packet-derived Research Block
  machinery is removed from schemas, projection construction, reads, routes,
  UI, tests, and operator documentation.
- Projection and Activity start from clean current schemas. Hosted Activity is
  limited to membership, notes, canvas updates, scientific Approaches,
  Attempts, Research Blocks, and unsigned Submission preparation.
- Generic Git-work sessions, transcripts, checkpoints, resume, and search are
  not duplicated here. When Entire captured them they remain external work
  provenance; otherwise they are unavailable without affecting Vela replay or
  Standing.
- The canonical Math input is the public `coh-00` lineage with Repository ID
  `8138c6da-46c4-47ee-b493-5bbfbec09b1e`.

The projection and hosted Workspace remain non-authoritative. Only an
authorized Vela Decision changes Standing.
