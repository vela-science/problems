# Observatory v0.360.3 release evidence

This operational patch removes the projection pipeline's dependency on ignored
local Decision Plan preimages. Those preimages are optional inspection
evidence, not canonical frontier state.

The projector now derives every proposal summary from released Vela over the
canonical Git checkout, retains the Decision Plan root committed by the signed
event, and verifies the published Erdős decision against its proposal,
standing, Receipt root, event ID, Decision Plan root, and exact reason. Missing
optional preimage bytes are not silently promoted to verified evidence.

No protocol, authority, canonical frontier, editorial, or accepted-state byte
changes in this patch.
