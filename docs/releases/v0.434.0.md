# Vela Web v0.434.0

Vela Web 0.434.0 opens the first external frontier-to-commons source lane with
an exact, read-only Physlib API-map observation.

- The Math Source Registry now binds Physlib commit
  `ad1d812c1cfd269898282081384bd92aef33b278` and tree
  `c66f558b2dc25bbc85c51123c72b319c1a2ad91b`.
- The adapter projects all 232 requirements from the 20 native
  `Physlib/**/API-map.yaml` files: 171 source-reported implemented and 61
  source-reported planned. It preserves the current source irregularities
  rather than normalizing them.
- Each record binds its exact API map, declared Lean source files, Lean 4.32.0
  toolchain, Lake inputs, Apache-2.0 license, AI policy, agent guidance, API-map
  guide, and review guidelines.
- Source rows now expose attributed implementation state and a direct native
  source link. The Physlib detail surface provides focused paths to planned and
  implemented requirements.
- Two clean local PostgreSQL reconstructions produced the same release root,
  table roots, and SELECT-only reader result.

A Physlib `done: true` value remains attributed native map state. This release
does not run Lean or Physlib linters, open an upstream pull request, import a
maintainer Decision, establish statement fidelity, or change Vela Standing.
