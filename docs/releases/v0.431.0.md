# Vela Web v0.431.0

Vela Web 0.431.0 publishes the first Result Dossier that is genuinely reused
across Frontiers.

- The Formal Conjectures Frontier now exposes the Erdős 521 exact proof
  qualification as one read-only HTML and JSON case record.
- The dossier binds the open official and upstream source state, exact formal
  blob, pinned Lean proof corpus, compiled statement bridge, scoped
  Verification, attributed human Decision, clean replay, shared dependencies,
  nonclaims, and bounded next actions.
- Frontier overviews now surface their Result Dossiers directly instead of
  requiring a reader to discover them through search or an individual Claim.
- The dossier reading order begins with the four 90-second triage judgments,
  then exposes the eight-question evidence map and full case chain.
- The projection and release documentation now use the published Vela 0.966.1
  verifier. The database remains the single unnumbered current Observatory
  projection; it has no separate product version.

This release does not change official Erdős Problems status, merge an upstream
Formal Conjectures pull request, claim novelty or external review, or establish
general statement-fidelity, usability, adoption, or productivity results.
