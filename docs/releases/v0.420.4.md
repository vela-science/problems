# Vela Web v0.420.4

Vela Web 0.420.4 keeps the sole Observatory projector current when a Profile
v1 Frontier has committed derived views from a different compatible Vela
reducer.

The projector still requires a clean exact `origin/main` checkout and verifies
the released Vela status, Git identity, event root, scientific-state root,
proposal root, actor registry, artifact root, counts, packets, decisions, and
graph roots. For Profile v1 only, it now clones the already verified source
commit into a disposable directory and rematerializes that copy with the
projector's pinned released Vela binary before reading derived state. The
canonical checkout remains byte-identical.

The materialized scientific-state and event roots must match the released
status exactly. Legacy frontiers, scientific-root drift, event-root drift,
wrong source commits, dirty checkouts, and arbitrary materialization failures
still fail closed.

This is a read-projection compatibility repair. It changes no Frontier,
protocol, authority, or accepted scientific state.
