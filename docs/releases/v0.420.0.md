# Vela Web v0.420.0

This release makes the public reader compatible with the released Vela 0.914
frontier contract and makes its own deployment identity truthful.

- The read-only frontier projection understands profile-v1, dual-root object
  identity, grouped finding relationships, and migration blockers emitted by
  Vela 0.914.
- Finding and graph records retain exact object context without introducing a
  second ontology or changing scientific standing.
- Production builds fail unless an explicitly registered Web tag and commit
  match Vercel's immutable Git commit. The local release gate separately proves
  that the tag resolves to that commit; preview builds remain untagged
  candidates.
- Semantic-correction mapping stays in focused conformance tests. It is not a
  runtime Web abstraction, protocol primitive, or authority surface.
- Vercel build filtering and projection checks are hardened without changing
  canonical frontier history or public authority semantics.

The Observatory remains a read-only projection of canonical Git frontiers.
Verifier evidence, proposal standing, and scientific acceptance remain
distinct.
