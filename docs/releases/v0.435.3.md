# Vela Web v0.435.3

Vela Web 0.435.3 adopts WorkOS's documented Next.js sign-out path.

- A narrowly scoped server action calls the maintained AuthKit `signOut`
  primitive.
- The persistent account form invokes that action without a custom sign-out
  Route Handler.
- Next.js supplies the server-action origin boundary; WorkOS deletes the app
  cookie, ends the provider session, and returns to `/problems`.
- The Observatory boundary gate permits only this exact product-identity server
  action and still rejects scientific mutation surfaces.

Human web identity remains separate from Vela actor identity and carries no
scientific authorship, signature, Verification, Decision, or repository
authority.
