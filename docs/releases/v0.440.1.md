# Vela Web v0.440.1

Vela Web 0.440.1 makes the frontier movement timeline actually render.

- The 0.440.0 timeline reader typed `committed_at` as a string, but the live
  database driver hands timestamptz columns over as Date objects. The reader
  threw on every real row, and the page's fail-closed degraded state rendered
  the section as absent instead of surfacing the defect. The reader now
  normalizes both representations to one ISO instant, and the fixture suite
  replays the driver's Date shape so the mismatch cannot return.
- `read-contracts.ts` carried a literal NUL byte inside a map-key template,
  which made text tools classify the source file as binary and silently
  exempt it from every sweep. The byte is now written as the `\u0000` escape; the
  runtime key is unchanged.

The executed journey found both defects; no schema, table, or manifest
changed. Only an authorized Vela Decision changes Standing.
