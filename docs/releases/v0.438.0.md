# Vela Web v0.438.0

Vela Web 0.438.0 adds the bounded connected-codebase onboarding loop to the
single Problems application.

- WorkOS GitHub identity and GitHub App repository access remain separate
  hosted axes; neither is Vela identity or Repository authority.
- The read-only GitHub App retains selected-repository metadata and Contents
  access only. Short-lived installation tokens and private source bytes are
  never stored in Neon, HTML, logs, or Vela objects.
- GitHub App and manual public URL imports pin the same immutable commit and
  tree, run the same Core native-integration inspection, and retain one rooted,
  authority-free receipt.
- Installation webhooks are signature-verified and delivery-deduplicated.
  Uninstall and access removal stop future private reads without rewriting
  canonical scientific history.
- Account Connections, Import, and connected-codebase views show exact revision,
  integration status, limitations, and local CLI/workbench handoff. There is no
  hosted signer, GitHub write permission, automatic Verification, Decision, or
  Standing mutation.

The scientific projection and hosted Activity planes remain non-authoritative.
Only an authorized Vela Decision changes Standing.
