# Vela Web v0.439.0

Vela Web 0.439.0 moves the pinned projection generator from signed Vela
0.977.2 to signed Vela 0.977.3.

- `vela.release-record.v1` now declares the v0.977.3 release: commit
  `1c1abe8f365f16803fea889bf9280877992a6d02`, both generator binary digests,
  and both archive digests, taken from the signed release manifests.
- Vela 0.977.3 changes no wire object, projection schema, or Decision,
  Event, or Standing semantics; it adds exact recovery inspection after
  restart to the CLI. The vendored status and submission schema bytes are
  unchanged, so this release re-pins the same schemas at the new commit.
- The bounded Core integration inspector and the Linux acquisition path in
  `prepare-vela.mjs` fetch and verify the v0.977.3 artifacts by digest.
- The previously pinned 0.977.2 generator binary is no longer present on the
  release operator machine, so the 0.977.2 pin could no longer regenerate a
  projection. This release restores a refreshable production.

The scientific projection and hosted Activity planes remain non-authoritative.
Only an authorized Vela Decision changes Standing.
