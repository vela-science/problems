# Vela Web v0.430.1

Vela Web 0.430.1 makes the Observatory release path atomic and publishes the
current Result Dossier projection.

- The operator-facing product release remains Vela Web; the disposable database
  has no parallel numbered release train.
- Relevant `main` changes now run one ordered workflow: rooted SQL migrations,
  exact projection build and verification, activation, then Vercel deployment.
- Direct Vercel Git deployment is disabled for the Observatory, removing the
  race that briefly paired current application code with the predecessor read
  model.
- The public projection binds Erdős Frontier commit
  `9ecb63bc97ccb8b403b4088e15c54499ab4e95f6` and exposes the Erdős 264 and 730
  Result Dossiers as read-only, non-authoritative HTML and JSON records.

This release does not claim reviewer-efficiency, adoption, productivity,
external validation, scientific acceptance, or causal Vela lift.
