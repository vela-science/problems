# Vela Observatory v0.390.0

Vela Observatory 0.390.0 replaces its bespoke presentation layer with the pinned official shadcn `base-nova` registry over Base UI. The scientific projection, rooted read APIs, canonical state, and authority boundary are unchanged.

## Product result

- Collections use official table, item, filter, pagination, and sheet compositions.
- Records lead with the scientific object and defer exact roots to one disclosure.
- Graph and search remain URL-addressable instruments with official controls and accessible record equivalents.
- Light is the default; dark is an explicit persisted preference.
- The application CSS fell from 752 to 141 lines. Superseded ledgers, cards, headers, disclosures, route CSS, and the unused virtualization dependency were removed.
- The repository does not publish a custom shadcn registry. The official registry remains the source until a second React product needs the same stable Vela primitives.
