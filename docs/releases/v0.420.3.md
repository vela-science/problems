# Vela Web v0.420.3

Vela Web 0.420.3 repairs the only product defect exposed by the completed
minimum read-network comparison: the Observatory could retain stale Git source
identities after canonical Frontier repositories advanced.

The release keeps one projector and one disposable Neon read model:

- the projector now uses released Vela `0.915.1`;
- Erdős and Formal repository trust anchors are installed from the typed source
  registry;
- clean current Frontier tips rebuild successfully without changing canonical
  scientific history;
- unchanged projection facts are a no-op rather than a new timestamp-derived
  release;
- the refresh cadence is three hours instead of one day;
- refresh is bound to the exact deployed application commit;
- deploy-hook timeout is resolved by checking the expected production
  projection root; and
- a changed projection is the only condition that triggers pruning and
  deployment;
- the sole application reader credential was rotated, remains schema-scoped
  and SELECT-only, and is held only by Vercel and the refresh workflow; and
- the obsolete `observatory_reader` credential was invalidated and discarded
  while its empty role remains only for replaying the immutable migration
  history.

The Atlas/Tapestry experiment remains source-local. This release adds no
relay, lens, public API product, database, authority operation, protocol
object, canonical scientific state, or second projector.
