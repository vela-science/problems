# Observatory v0.360.6 release evidence

This patch closes the final cross-deployment usability defect found during the
v0.360 Browser audit.

- Next.js now receives one explicit, unique, URL-safe deployment identifier for
  every Vercel build. Client navigations and static assets therefore remain
  bound to one immutable deployment, and a version mismatch triggers a hard
  navigation instead of leaving a partially hydrated route.
- Vercel's internal `dpl_` prefix is removed only for the framework identifier;
  the public deployment manifest continues to record the complete Vercel
  deployment identity.
- Local development remains unbound. CI builds use the bounded source revision,
  and malformed explicit identifiers fail the build.

No canonical frontier, protocol, authority, editorial, or accepted-state byte
changes are included.
