# Observatory v0.360.6 stopped release evidence

This tagged build did not reach production. Vercel stopped it before route
generation because the candidate transformed Vercel's injected deployment ID,
while Next.js requires the configured and injected identifiers to match
exactly. The production alias remained on v0.360.5.

The failure is retained as release evidence instead of moving or deleting the
published tag. v0.360.7 corrects the configuration by preserving the exact
platform-provided identifier.

No canonical frontier, protocol, authority, editorial, or accepted-state byte
changes are included.
