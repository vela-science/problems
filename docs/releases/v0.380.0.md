# Observatory v0.380.0 release evidence

This release replaces the remaining bespoke Observatory presentation layer
with the current shadcn `base-nova` registry on Base UI while preserving the
rooted Neon read model and every scientific-state distinction.

## Component contract

- The workspace uses `shadcn` 4.13.1, Base UI 1.6.0, Tailwind CSS 4, React
  19.2.7, and Next.js 16.2.10.
- All 19 installed registry components were refreshed from the current
  `base-nova` source. A post-migration registry diff reports no local drift.
- Official Cards, Tables, Dropdown menus, Buttons, Inputs, Tabs, Sidebar,
  Sheets, Dialogs, Badges, Progress, and Selects provide the primitive layer.
  Vela-specific code now composes records and provenance rather than
  reimplementing those controls.
- Fourteen superseded Observatory presentation components were deleted. The
  surviving product vocabulary is `ObjectHeader`, `StatusBadge`,
  `StatusDistribution`, `SummaryCard`, `ProvenanceTrail`, and
  `RootDisclosure` plus the workflow ledgers.
- Product typography is Geist with IBM Plex Mono reserved for identifiers and
  exact values. Observatory delivery no longer copies the unused Inter asset.

overflow, and distinct replay, strict-blocked, pending, applied, rejected,
